# 😷 Face Mask Detection using Deep Learning

This project detects whether a person is wearing a face mask or not using a Convolutional Neural Network (CNN) built with Keras and TensorFlow.

---

## 🧠 Overview

The goal of this project is to train a deep learning model capable of classifying images of faces into two categories:
- `With Mask`
- `Without Mask`

---

## 📁 Project Structure

- `Untitled-1.ipynb`: Jupyter Notebook containing the full code:
  - Data preprocessing and augmentation
  - CNN model building and training
  - Accuracy and loss visualization
  - Testing on sample images

---

## 📦 Technologies Used

- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
